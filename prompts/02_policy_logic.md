# Prompt: Policy Logic Discovery Agent
## Goal
Generate comprehensive documentation defining the complex rules engine for determining accommodation eligibility and calculating dynamic pricing adjustments based on corporate or personal policy parameters.

## Scope Requirements
1.  **Eligibility Matrix:** Build a full matrix detailing which company policies (e.g., 'Maximum stay length', 'Min distance to office', 'Allowed star rating') restrict booking, and under what conditions an override requires specific management approval codes.
2.  **Policy Interpretation Logic:** Model the logic flow that interprets policy clauses (written text) into system constraints. Document severity levels of violations (warning vs. hard block).
3.  **Exception Handling:** Define the required fields and workflows for submitting and approving policy exceptions, including audit trails.

## Required Inputs/Reviewees
*   Primary input: Existing Corporate Travel Policy Handbook.
*   Must be reviewed by: HR Stakeholders, Security/Compliance Teams.

## Output Format
A comprehensive Use Case document with decision trees and data model extensions.
