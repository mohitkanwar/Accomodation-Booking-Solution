# Ownership and RACI

| Area | Expected accountable stakeholder |
| --- | --- |
| Product scope and employee experience | Sodexo product with Tetrapak sponsor |
| Client policy and destinations | Tetrapak / Client Administrator |
| B2C platform and Lego integration | Sodexo Platform |
| Accommodation domain architecture | Sodexo Architecture and Engineering |
| Operator process and SLA | Client operations / Operator Supervisor |
| Booking.com contract and affiliate account | Commercial owner to be confirmed |
| Payment and reconciliation model | Finance and Procurement |
| Security and privacy | Security and Data Protection |
| Supplier technical onboarding | Integration owner |

A complete RACI is a required discovery output.
