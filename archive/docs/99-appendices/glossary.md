# Glossary

| Term | Definition |
| --- | --- |
| ADR | Architecture Decision Record |
| Affiliate ID | Booking.com partner identifier required for Demand API calls |
| B2C | Existing Sodexo business-to-consumer application platform |
| BFF | Backend-for-Frontend |
| Booking confirmation | Supplier-confirmed reservation, distinct from approval |
| Demand API | Booking.com accommodation and order API |
| Idempotency | Repeating a command without creating an additional business effect |
| Lego | Micro frontend integrated into the B2C platform |
| Merchant of record | Entity legally responsible for the customer transaction |
| Outbox | Persisted delivery intent committed with business state |
| Policy snapshot | Immutable request-time record of entitlement evaluation |
| Reconciliation | Comparison and correction of internal and external transaction state |
| Supplier adapter | Internal boundary that maps Booking.com to domain contracts |
| Tenant | Client organisation isolated within the platform |
| Uncertain outcome | External command may have succeeded, but no definitive response was received |
