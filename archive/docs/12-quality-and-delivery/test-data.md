# Test data

Test data should cover multiple tenants, employee levels, countries, sites,
currencies, policy precedence levels, compliant and non-compliant offers,
variable nightly rates, taxes, cancellation terms, missing mappings, price
change, unavailability, timeout, and cancellation fees.

Personal data should be synthetic. Supplier sandbox fixtures and identifiers
must be isolated from production.
