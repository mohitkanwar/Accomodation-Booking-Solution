# Target state

The target state is a multi-tenant, policy-aware accommodation request and
operator-booking capability integrated with the Sodexo B2C platform.

It provides employee search and request, client administration, operator
approval and exception management, Booking.com order execution, notifications,
audit, resilient recovery, and later post-booking optimisation through an
internal supplier abstraction.
