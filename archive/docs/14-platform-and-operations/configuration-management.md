# Configuration management

| Configuration | Owner and storage |
| --- | --- |
| Base URL and API version | Platform environment configuration |
| Affiliate ID and token | Secret management |
| Timeout and retry policy | Technical administration |
| Search defaults | Business administration |
| Feature toggle | Technical administration |
| Sandbox / production mode | Deployment configuration |
| Clients, roles, sites, and policies | Versioned business administration |

Business configuration is typed, effective-dated, validated, and audited.
Secrets are never readable business records.
