# Technology standards

The source identifies:

- React micro frontend conforming to the existing B2C Lego contract and design
  system;
- authenticated API Gateway or B2C backend integration;
- server-side BFF and domain services;
- database, cache, outbox, scheduler, audit, and secret vault;
- versioned adapter and contract tests.

Programming language, runtime, database engine, cloud platform, messaging
technology, and observability stack have not been selected.
