# API catalogue

## Employee-facing internal APIs

- Load identity-derived accommodation context.
- List destinations and sites.
- Resolve policy summary.
- Search accommodation.
- Retrieve property and availability details.
- Revalidate selected offer.
- Create and retrieve booking requests.
- Retrieve confirmed reservation.
- Request cancellation.

## Operator APIs

- Query and prioritise work queue.
- Retrieve request evidence and alternatives.
- Request information, approve, reject, escalate, or override.
- Preview, create, retrieve, and cancel supplier booking.
- Add notes and attachments and resend confirmation.

## Administration APIs

- Manage clients, levels, role mappings, destinations, policies, approval
  rules, operator access, and auditable configuration.

Detailed paths and schemas are not yet defined.
