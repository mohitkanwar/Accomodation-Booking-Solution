# Delegation and approvals

The default model is employee request followed by operator approval and
operator-triggered booking.

Open decisions:

- Can an assistant request or book for an executive?
- Can requester and traveller differ?
- Is approval mandatory for every request?
- Who approves policy exceptions?
- May operators change the selected accommodation?
- What override value or percentage requires supervisor approval?
- Can compliant requests be auto-approved in a later phase?

Every delegated or overridden action must record the actor, authority, reason,
and affected traveller.
