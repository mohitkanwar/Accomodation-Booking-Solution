# Domain overview

The accommodation domain coordinates five concerns:

1. Trusted employee and tenant context.
2. Client destinations and effective-dated travel policy.
3. Supplier accommodation search, details, availability, and order operations.
4. Employee request, approval, exception, booking, and cancellation workflow.
5. Auditable evidence, notifications, and uncertain-transaction recovery.

The domain should use internal models and a supplier abstraction rather than
expose Booking.com request and response structures directly.
