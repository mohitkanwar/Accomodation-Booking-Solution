# Hotel and property model

The normalised property view should include:

- supplier property identifier;
- name, images, location, and map coordinates;
- distance from the selected client office;
- accommodation type and property category;
- rating and review score;
- facilities, accessibility, and sustainability indicators where supplied;
- available room and rate summary;
- applicable policies and restrictions.

The internal model must not expose supplier-specific structures directly to the
business domain or React application.
