# Partner classification

| Partner class | Partners | Criticality |
| --- | --- | --- |
| Supply and booking | Booking.com | Critical to search and integrated booking |
| Identity | Existing B2C / Identity Provider | Critical to every authenticated operation |
| Communications | Email, push, B2C inbox | Important; asynchronous degradation is possible |
| Platform security | Enterprise secret vault | Critical to supplier access |
| Location | Map provider | Important to map experience; list alternative required |
| Financial | Payment provider, card service, finance / ERP | Critical but not selected |
| Reference data | FX provider | Required where policy and offer currencies differ |

Commercial, security, privacy, operational, and exit responsibilities must be
defined for each selected partner.
