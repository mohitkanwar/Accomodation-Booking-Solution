# Documentation archive

This directory preserves documentation that is not part of the current
discovery-workshop navigation.

The published Docusaurus content is intentionally limited to:

- `docs/index.md`
- `docs/presentation/`

Archived pages retain their original directory structure under `archive/docs/`
so they can be reviewed, reused, or restored later without appearing in the
site build.

Content in this archive is not maintained as part of the active workshop
documentation and may contain assumptions that have since changed.
