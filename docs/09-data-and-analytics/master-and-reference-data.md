# Master and reference data

Reference data includes clients, employee levels, role mappings, country and
currency codes, destination sites, policy reason codes, property categories,
facilities, booking statuses, cancellation outcomes, and supplier error
classifications.

Destination configuration includes country, city, office name, address,
coordinates, active status, default radius, preferred neighbourhoods,
destination currency, and applicable policies.
