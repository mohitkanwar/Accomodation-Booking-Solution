# Data lineage

```text
Identity Provider
  → authenticated employee/client/role context
  → entitlement resolution

Client Administration
  → destination and effective policy
  → policy evaluation snapshot

Booking.com
  → property, offer, availability, price and terms
  → selected offer snapshot
  → booking preview and confirmation snapshot

Operator decisions
  → approval and override records
  → request and booking state
  → notifications, audit and reconciliation
```

Correlation identifiers connect each lineage step.
