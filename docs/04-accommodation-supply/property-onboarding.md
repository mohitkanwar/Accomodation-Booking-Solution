# Property onboarding

Properties are expected to come from Booking.com Demand API inventory rather
than being onboarded individually into the accommodation domain.

Discovery must confirm affiliate eligibility, production access, permitted use
in an employee-only corporate application, available rate types, content
caching permissions, attribution requirements, and support responsibilities.

Client destination offices are onboarded separately through administration and
are used for policy, distance, map, and search context.
