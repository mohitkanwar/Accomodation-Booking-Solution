# Accommodation Booking Solution discovery video v0.4

This package was produced from `Accommodation-Booking-Solution-Discovery-Presentation-v0.4.pptx`.

## Deliverables

- `Accommodation-Booking-Solution-Discovery-Session-v0.4.mp4` — complete 47-slide reference session with embedded slide chapters.
- `Reviewed-Narration-v0.4.txt` — human-readable reviewed narration and delivery direction for every slide.
- `Reviewed-Narration-v0.4.json` — structured narration source.
- `slide-timings.json` — exact chapter and slide timing data.
- `audio/slide-01.mp3` through `audio/slide-47.mp3` — normalised per-slide voice tracks.

## Production notes

- Narration was revised from presenter instructions into natural spoken language while preserving the deck's facts, open questions, recommendations and provisional assumptions.
- The spoken approach is calm, conversational and appropriate for a senior solution architect leading a discovery session. The recurring traveller scenario remains subtle and no artificial participant dialogue was added.
- Speech was generated with the OpenAI speech API using the `gpt-4o-mini-tts` model and `cedar` voice. The voice in these files is AI-generated.
- Master video: H.264, 1280×720, 30 fps.
- Master audio: AAC mono, 48 kHz, approximately −16.8 LUFS integrated, −0.7 dBFS true peak.
- Runtime: 40 minutes 38 seconds.

- Final slide chapters and media duration were checked against `slide-timings.json`.
