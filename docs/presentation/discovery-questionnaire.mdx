# Discovery Workshop Questionnaire

Use this questionnaire to capture facts, decisions, assumptions, and unknowns
with business, product, operations, security, and technology stakeholders.
Save partial answers during the workshop and return to the same browser later.

:::info Where answers are saved

The **Save answers** button stores the questionnaire in this browser's local
storage. Nothing is sent to a server, and answers do not automatically sync
between browsers or devices. Use **Download JSON** when you need a portable
copy or a workshop record.

:::
