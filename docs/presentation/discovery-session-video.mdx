## Session structure

| Time | Topic |
| ---: | --- |
| 00:00 | Purpose, context and the traveller promise |
| 02:19 | Context, success criteria and release scope |
| 17:37 | Discovery questions and blocking decisions |
| 23:55 | Data model, architecture and Lego boundary |
| 33:53 | Failure paths, resilience and quality assumptions |
| 36:56 | Readiness workshops and owners |
| 38:44 | Questions and decision recap |

The video contains 47 embedded chapters—one for each source slide. Exact
chapter boundaries are also available in the
<a href="https://raw.githubusercontent.com/mohitkanwar/Accomodation-Booking-Solution/main/docs/presentation/assets/accommodation-discovery-video-v0.4/slide-timings.json">slide-timing data</a>.

:::note Reference-session format

This recording demonstrates how a senior architect can guide the material as
a working discovery conversation. Recommendations and quality targets remain
provisional where the source presentation identifies them as assumptions or
open decisions.

:::
