# Business glossary

| Term | Meaning |
| --- | --- |
| Accommodation Lego | React micro frontend embedded in the B2C application |
| Booking request | Employee-submitted request awaiting operator action |
| Booking | Confirmed supplier reservation |
| Client | Tenant organisation whose employees use the service |
| Destination site | Client office or site used for location and policy context |
| Employee level | Role grouping used to resolve travel entitlement |
| Entitlement | Accommodation limits and conditions available to an employee |
| Operator | User who reviews requests and creates supplier bookings |
| Policy snapshot | Immutable copy of the policy result used for a request decision |
| Proposal | Property, room, rate, price, and terms offered to the employee |
| Supplier | External accommodation inventory and booking provider |
| Uncertain booking | Booking attempt whose external outcome is not yet known |
