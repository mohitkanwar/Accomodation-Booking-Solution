# PCI and payment security

Payment handling is unresolved. Before selecting a flow, confirm whether card
data is entered or transmitted by the operator, employee, supplier, property,
or a payment provider, and whether the contracted API permits that flow.

No card information should be introduced into the accommodation application
until PCI scope, tokenisation, storage prohibition, masking, support access,
and accountability are approved.
