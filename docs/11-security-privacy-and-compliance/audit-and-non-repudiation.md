# Audit and non-repudiation

Audit captures employee submission, policy evaluation and displayed result,
selected offer, price change, operator decision, override, order preview,
booking attempt, supplier response, cancellation, and administrative change.

Each event records entity, event type, actor and actor type, timestamp, old and
new values where appropriate, and correlation identifier.

Sensitive fields are redacted. Audit persistence permits no silent loss.
