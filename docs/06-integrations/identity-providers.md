# Identity providers

The existing B2C authentication mechanism or a trusted identity service
provides employee subject, client, role, authentication level, and locale.

The integration must also establish the authoritative source for employee
level, active status, manager, department, and cost centre where required.
Missing or unreliable role data is a major delivery risk because it can produce
incorrect entitlements.
