# Integration certification

Testing should combine:

- mocked supplier responses for unit and component tests;
- consumer and provider contract tests for adapter mappings;
- Booking.com sandbox scenarios for search, booking, payment, and cancellation;
- controlled production smoke tests after onboarding.

Certification criteria and formal Booking.com approval steps remain to be
confirmed with the affiliate onboarding team.
