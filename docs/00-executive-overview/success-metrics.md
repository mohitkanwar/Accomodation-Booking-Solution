# Success metrics

The discovery material defines initial service targets but does not yet provide
business outcome targets.

## Initial service measures

| Measure | Initial target |
| --- | --- |
| Employee search and request availability | 99.9% monthly |
| Operator booking availability | 99.9% monthly |
| Administrative availability | 99.5% monthly |
| Audit persistence | No silent loss |
| Booking execution | Idempotent and recoverable |
| Configuration load | p95 below 1 second |
| Destination load | p95 below 1 second |
| Request submission | p95 below 2 seconds |
| Operator queue load | p95 below 2 seconds |
| Policy evaluation | p95 below 200 ms |

## Business measures requiring definition

- Search-to-request conversion.
- Request-to-booking conversion.
- Policy-compliant selection rate.
- Exception and rejection rate.
- Median operator handling time and request ageing.
- Price-change and availability-loss rate.
- Booking failure, uncertain booking, and duplicate booking rate.
- Employee satisfaction and support-contact rate.
- Savings or avoided overspend against policy.
