# Stakeholders

| Stakeholder | Responsibility |
| --- | --- |
| Employee | Searches accommodation and submits a request |
| Traveller | Stays at the property and may differ from the requester |
| Operator | Reviews and processes requests and completes bookings |
| Operator Supervisor | Handles exceptions, escalations, and high-value cases |
| Client Administrator | Configures Tetrapak policies and destinations |
| Sodexo Platform Administrator | Manages technical and tenant-level settings |
| Finance and Procurement | Defines payment, budget, invoice, and reconciliation requirements |
| Security and Data Protection | Reviews personal data, credentials, access, and retention |
| Booking.com | Supplies accommodation inventory and enabled order capabilities |
| Identity Provider | Supplies authenticated identity, client, and role context |

Employee policy segments currently identified are General Employee, Director,
and C-Level Employee.
