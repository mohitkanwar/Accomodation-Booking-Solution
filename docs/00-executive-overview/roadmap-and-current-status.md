# Roadmap and current status

## Current status

The solution is in discovery. The conceptual architecture, business journeys,
policy model, initial state model, core entities, risks, NFRs, and delivery
phases have been identified. Commercial access, payments, exact policy
calculations, authoritative role data, and post-booking responsibilities remain
open.

## Delivery outline

1. **Commercial and technical validation** — confirm affiliate eligibility,
   capabilities, API version, payment model, sandbox access, privacy position,
   technical spike, and operating model.
2. **Search and request MVP** — implement policy-aware search, request,
   operator queue, manual external completion, notifications, administration,
   and audit.
3. **Integrated operator booking** — add availability recheck, order preview,
   order creation, confirmation, failed-booking recovery, and reconciliation.
4. **Post-booking and optimisation** — add cancellation, supported
   modification, messaging, finance reconciliation, analytics, automated
   approval, recommendations, and supplier abstraction.

Phase 0 is a hard gate before committing to integrated booking scope.
