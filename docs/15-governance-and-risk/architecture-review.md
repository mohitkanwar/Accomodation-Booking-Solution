# Architecture review

Review should confirm:

- B2C integration and trust boundaries;
- domain decomposition and ownership;
- server-side supplier and policy controls;
- tenant isolation;
- idempotency and uncertain booking recovery;
- payment and PCI scope;
- personal-data minimisation and retention;
- API version isolation;
- performance and supplier quota;
- operability, reconciliation, and continuity;
- delivery phases and reversible decisions.
