# Rollout and feature flags

Booking.com integration enablement is technical administration and deployment
configuration, including sandbox or production mode.

The phased plan supports separate enablement of search and request, manual
operator completion, integrated booking, cancellation, and later automation.

Detailed client rollout, pilot groups, feature-flag ownership, and exit
criteria are not defined.
