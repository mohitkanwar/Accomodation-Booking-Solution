# Delivery increments

## Phase 0 — Commercial and technical validation

Affiliate and capability confirmation, API version, payment decision, sandbox,
technical spike, data-protection review, and operating model.

## Phase 1 — Search and request MVP

Destinations, policy, search, list, filters, map, proposal, compliance,
request, queue, manual external completion, notifications, administration, and
audit.

## Phase 2 — Integrated operator booking

Availability recheck, preview, order creation, confirmation, cancellation
terms, notifications, recovery, and reconciliation.

## Phase 3 — Post-booking and optimisation

Cancellation, supported modification, messaging, financial reconciliation,
dashboards, analytics, recommendations, automated approval, and future
suppliers.
