# Service level objectives

| Capability | Initial objective |
| --- | --- |
| Employee search and request | 99.9% monthly |
| Operator booking functions | 99.9% monthly |
| Administrative functions | 99.5% monthly |
| Audit persistence | No silent loss |
| Booking execution | Idempotent and recoverable |

Error-budget policy, measurement windows, exclusions, and supplier-dependency
treatment are not yet defined.
