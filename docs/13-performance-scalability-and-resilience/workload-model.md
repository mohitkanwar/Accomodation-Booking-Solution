# Workload model

Inputs still required:

- number of B2C clients and Tetrapak employees;
- monthly active travellers;
- peak concurrent searches;
- search-to-request conversion;
- operator population;
- booking volume by country;
- seasonal peaks;
- typical and maximum stay length and room count.

Search, policy evaluation, queue operations, booking commands, notifications,
and reconciliation have different workload and latency profiles and should be
modelled separately.
