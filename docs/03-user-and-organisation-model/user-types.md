# User types

- Employee requester.
- General Employee.
- Director.
- C-Level Employee.
- Traveller, potentially different from the requester.
- Operator.
- Operator Supervisor.
- Client Administrator.
- Sodexo Platform Administrator.
- Finance or Procurement stakeholder.
- Security or Data Protection stakeholder.

The discovery must confirm contractors, assistants acting on behalf of
executives, accompanying guests, and employees who have left the company but
still require booking support.
