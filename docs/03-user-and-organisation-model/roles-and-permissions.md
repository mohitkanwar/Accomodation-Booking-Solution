# Roles and permissions

Recommended permissions:

```text
ACCOMMODATION_SEARCH
ACCOMMODATION_REQUEST_CREATE
ACCOMMODATION_REQUEST_VIEW_OWN
ACCOMMODATION_REQUEST_CANCEL_OWN
ACCOMMODATION_REQUEST_VIEW_ALL
ACCOMMODATION_REQUEST_REVIEW
ACCOMMODATION_REQUEST_OVERRIDE_POLICY
ACCOMMODATION_BOOK
ACCOMMODATION_CANCEL_BOOKING
ACCOMMODATION_POLICY_VIEW
ACCOMMODATION_POLICY_MANAGE
ACCOMMODATION_INTEGRATION_MANAGE
```

Role-level entitlement and application authorisation are separate concerns. An
employee level determines travel policy; permissions determine allowed system
actions.
